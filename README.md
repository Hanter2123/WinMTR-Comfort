# WinMTR Comfort 2.0

Портативная программа для Windows x64: измерение ответов ICMP и маршрута, графики и отчёты. Новый интерфейс на C++/Win32 использует подход WinMTR Redux с отдельными проверками TTL. Это самостоятельная реализация интерфейса, а не сборка оригинального MFC-приложения.

## Возможности

- До трёх целей одновременно: например, роутер, внешний узел провайдера и сервер.
- Графики на общей шкале времени; таблица и график отдельного TTL.
- Выделение периода мышью: пересчёт статистики и экспорт выбранного периода.
- Время начала и остановки в UTC и местном времени, часовой пояс, длительность.
- Тайм-ауты и ошибки ICMP учитываются отдельно. Ответ с задержкой 0 мс остаётся успешным ответом.
- Автосохранение каждые 10 секунд и при остановке; открытие и продолжение сохранённых сеансов.
- Интервал 0,2–60 секунд, тайм-аут 200–30000 мс, выбор IPv4/IPv6, история 20 адресов.
- TXT, CSV, автономный HTML с графиками; кнопка «Для провайдера» сохраняет сводку и открывает её в браузере.

## Использование

Распакуйте архив в доступную для записи папку и запустите `WinMTR-Comfort.exe`. Заполните 1–3 адреса, нажмите «Начать». Первая цель по возможности заполняется локальным шлюзом. Нажмите «Стоп», чтобы завершить замер. Отправка отчёта провайдеру выполняется пользователем.

Папка `data` рядом с программой содержит настройки и сеансы `.wmtr`. При следующем запуске открывается последний исправный сеанс; «Продолжить» возобновляет его при неизменных целях и настройках. Пауза входит в общую длительность; во время паузы проверки не выполнялись. «Новый» начинает отдельный сеанс. Не публикуйте папку `data`: она содержит адреса и результаты ваших измерений.

## Ограничения измерений

Хранятся последние 3600 завершённых проверок на каждый TTL. Общие счётчики охватывают весь сеанс; статистика выделенного периода использует сохранённые проверки. Время точки — завершение проверки, включая ожидание тайм-аута. Проверки разных целей запускаются параллельно, но не в абсолютно одинаковый момент. При долгих тайм-аутах фактический интервал может превышать заданный.

Последний отображаемый TTL не всегда является конечным сервером. Промежуточные узлы могут ограничивать ответы ICMP; это не доказывает потерю транзитного или игрового трафика. Имена промежуточных узлов показываются как IP-адреса. Авто выбирает IPv4, если он доступен. Успешная работа IPv6 в текущей среде не подтверждена.

## Сборка

Windows, C++17. В Developer PowerShell для Visual Studio с установленным Windows SDK выполните `./build.ps1`. MFC не требуется. Локальная поставляемая сборка создана Zig 0.14.1.

```powershell
zig c++ -std=c++17 -O2 -municode -Wl,--subsystem,windows native/main.cpp -o WinMTR-Comfort.exe -lcomctl32 -lws2_32 -liphlpapi -lcomdlg32 -lgdi32 -luser32 -lshell32
```

Тесты: `tests/history_test.cpp`, `tests/session_test.cpp`. Интеграционная проверка: `WinMTR-Comfort.exe --self-test=build/live` (три loopback-цели, остановка, восстановление и продолжение; выход 0 означает успех). Создаёт только тестовые файлы рядом с указанным префиксом.
